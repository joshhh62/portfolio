# Portfolio

My personal site: projects, experience, skills and certifications in one page.

**Live:** [portfolio-joshith-sai.vercel.app](https://portfolio-joshith-sai.vercel.app)

A single self-contained `index.html` (HTML, CSS and vanilla JavaScript, no build step) with a dark-mode toggle, project filters by category and scroll-triggered counters. Deployed on Vercel.

To run it locally, open `index.html` in a browser.
